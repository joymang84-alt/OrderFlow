# OrderFlow
A simple order management web application designed to help small businesses record and manage customer orders.

# Features
  Add new customer orders 
  Edit existing orders
  Remove orders
  Calculate individual order totals automatically
  Calculate the grand total of all orders
  Save orders in browser local storage
  Responsive layout for smaller screens.
  
  # Technologies used 
    >HTML,CSS,JAVASCRIPT,BROWSER LOCAL STORAGE
